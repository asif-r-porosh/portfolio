# portfolio

Source for uraal.online. `portfolio.md` and `template.html` build into `dist/`.

## Files

- `portfolio.md`: all content. The front matter holds the page title, description, header, and footer. The body holds About, Find and Contact.
- `template.html`: page layout and CSS (inline). Placeholders such as `{{title}}` and `{{content}}` are filled by `build.js`.
- `build.js`: builds `dist/index.html`, and copies `cv.pdf` and `fonts/` into `dist/`.
- `cv.md`: CV source for markDo. The HTML comments inside it are layout metadata and must stay.
- `cv.pdf`: the CV served at `/cv.pdf`. Generated by markDo from `cv.md`; regenerate whenever `cv.md` changes.
- `fonts/`: IBM Plex Sans and IBM Plex Mono, subset to Basic Latin plus a few symbols (SIL OFL 1.1, licence included). The build warns when the content uses a character outside the subset.

## Edit

Find rows use the form `- [Title](url): description`. Links starting with `http` open with `rel="noopener"`.

## Build and preview

```
npm install
npm run build
python3 -m http.server 8000 --directory dist
```

Open http://localhost:8000. The build stops with an error when a required front matter key, `cv.pdf`, or the Find list is missing.

## Deploy

Push to `main`. Cloudflare Workers Builds runs `npm run build`, then `npx wrangler deploy`. A `wrangler.jsonc` pointing the assets directory at `./dist` may be needed if the first deploy asks for one. Pushes to other branches produce preview versions only.

## Regenerate the font subsets

```
pyftsubset IBMPlexSans-Regular.woff2 --unicodes="U+0020-007E,U+00A0,U+00A9,U+00B7,U+2014,U+2019,U+2197" --flavor=woff2 --layout-features='kern,liga' --output-file=plex-sans-400.woff2
```

The same command applies to the Light, Light Italic and SemiBold Sans files and to IBM Plex Mono Regular. Source files come from the `@ibm/plex-sans` and `@ibm/plex-mono` npm packages.
